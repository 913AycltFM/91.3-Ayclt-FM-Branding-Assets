Official archive of 91.3 Ayclt FM's logos, station artwork, channel branding, DJ graphics, studio backgrounds, and promotional images.

This repository preserves the station's visual identity and provides a central place to store and maintain its branding assets.

## What's Included

- Original 91.3 Ayclt FM logos and artwork
- HD2 and HD3 channel branding
- DJ and streamer graphics
- Studio backgrounds and promotional images
- Original branding archive ZIP

## Original Artwork Preservation

The original artwork is retained as supplied. Existing logos, colors, layouts, and designs should not be replaced, redrawn, or altered without approval.

When updated artwork is needed:
- Keep the original files unchanged.
- Save revised versions as separate files.
- Make only the specifically requested changes.
- Review updated artwork before using it across station platforms.
